Termos de Uso

VERSÃO ATUAL · ATUALIZADA EM 20/05/2026

Ao usar o WiNS Hub você concorda com os termos abaixo. Esta é uma versão de preview do v2 — a versão completa e juridicamente vinculante está disponível no site v1.

1. Coleta de dados

O WiNS Hub agrega dados públicos de fontes oficiais (ANEEL, BNDES, ANP, IBAMA, etc) e mídia setorial. Decisores são mapeados via LinkedIn público e enrichment de pattern de email.

2. Uso permitido

O conteúdo da plataforma é destinado à prospecção comercial B2B legítima. É proibido scraping massivo, redistribuição de dados de decisores ou uso para spam.

3. Cancelamento

Assinaturas podem ser canceladas a qualquer momento pelo painel /perfil. O acesso permanece até o final do período pago.
